# 문자 자동전달

수신 SMS 또는 카카오톡 **알림에 표시된 내용**을 규칙으로 검사해 지정 번호로 SMS 전달하는 개인용 Android 앱입니다.

## 사용

1. Android Studio에서 이 폴더를 열고 앱을 설치합니다.
2. 앱에서 SMS 수신/발송 권한을 허용합니다.
3. `카카오톡 알림 접근 설정 열기`를 눌러 `카카오톡 알림 전달`을 허용합니다.
4. 규칙을 추가합니다. 항목은 쉼표 또는 줄바꿈으로 구분합니다.

- 발신자: 정확한 번호/이름 또는 `01012*` 접두 대역
- OR: 하나 이상 포함하면 통과
- AND: 입력한 문자열을 모두 포함해야 통과
- 제외: 하나라도 포함하면 차단
- 빈 조건: 제한 없음

카카오톡 알림과 메시지 미리보기가 켜져 있어야 하며, 알림에 숨겨진 메시지는 읽을 수 없습니다. 제조사에 따라 앱 배터리 사용을 `제한 없음`으로 설정해야 할 수 있습니다.
