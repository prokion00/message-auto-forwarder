# 문자자동전달 1.0

갤럭시 S25(Android 16)용 개발 APK. 패키지 `com.personal.messageforwarder.diagnostics`를 유지하여 기존 규칙과 권한을 보존합니다.

정식 홈 화면에서 자동전달 상태, 발송 규칙, 발송 내역을 관리합니다. 권한 확인, 수신 원문과 테스트 SMS 기능은 `진단 및 테스트` 메뉴에 분리했습니다.

## 사용
1. 기존 SMS 읽기/수신/발송 권한과 RCS·카카오톡 알림 접근을 확인합니다.
2. 발신인, 본문 포함/제외 조건, 전송번호를 3단계 규칙에 등록합니다.
3. 메인 화면에서 자동발송 켜기를 누릅니다. 상태 알림 권한이 필요하면 허용 후 다시 누릅니다.
4. 확인 화면에서 전송번호를 확인하고 자동발송을 켭니다. 시작 시점 이후 새 메시지만 전달하며 과거 기록을 일괄 발송하지 않습니다.
5. 자동발송 내역에서 번호별 결과를 확인합니다. 앱 또는 상태 알림에서 중지할 수 있습니다. 이미 시스템에 요청한 SMS는 취소되지 않습니다.

## 동작
- 발송 본문: `[자동전송] ` + 받은 원문. 줄바꿈 유지, 긴 문자는 SmsManager로 분할하여 발송.
- SMS 수신 이벤트 및 SMS/MMS 저장소 조회, 삼성/Google 메시지·카카오톡 알림 지원.
- 메시지 앱 알림만으로 RCS/SMS/MMS를 확정하지 않으며 ‘메시지 알림’으로 표시.
- 구조화된 알림 발신인과 tel URI가 있으면 해당 번호를 사용. 제목 후보·불완전 정보·첨부 알림은 자동발송하지 않음.
- MMS는 다운로드 완료된 텍스트를 사용하며 첨부파일 자체는 전달하지 않음.
- 문자 저장소 변경 관찰 + 15초 간격 보조 조회를 foreground specialUse 서비스에서 실행. 앱 화면을 닫아도 서비스가 살아 있으면 감시 지속.
- 자동발송이 켜져 있으면 재부팅 완료 또는 앱 업데이트 완료 후 foreground 감시 서비스를 자동 복구.
- Android 절전/강제 종료 및 알림 미발생/숨김에 따른 지연·누락 가능. 사용자가 앱을 강제 종료한 경우에는 앱을 직접 다시 열어야 할 수 있음.
- 자동발송 상태 알림을 표시하며 Play 프로텍트/기본 문자 앱/배터리 보안 설정은 변경하지 않음.

## 중복과 실패
- 동일 이벤트·대상은 영구 SQLite 발송 장부로 재발송 차단. 규칙 중복 일치 시 전송번호별 1회.
- 같은 본문을 같은 번호로 2분 내 보내려는 경우 수신 경로/발신인이 달라도 차단. 실제 반복 메시지도 생략될 수 있음.
- `[자동전송]`으로 시작하는 수신 본문은 재전달하지 않음.
- 발송 전 장부 예약 후 시스템에 요청. 프로세스 종료/예외/실패 시 자동 재시도 없음.
- 분할 SMS 결과를 각 조각별로 기록. 일부 실패 시 전체 성공으로 표시하지 않음. 결과가 2분 넘게 없으면 미확인으로 표시.
- 발송 성공은 시스템 발송 결과이며 상대 단말 수신 확인과 다름.

## 검증
- 1.0 Android 빌드 및 lint 통과.
- S25 계측 테스트 27개 통과: 부팅/업데이트 복구 이벤트 판별, 시작 전 메시지/반복 전달 차단, 원문 형식, 포함·제외/미확인 판별, 번호 중복 제거, SQLite 원자적 예약, 재시작 중복 방지, 분할 결과 중복/순서/부분 실패 처리.
- 계측 테스트는 실제 SMS를 보내지 않음. 업데이트 후 자동발송은 꺼짐 상태. 사용자가 켠 뒤 실제 일치/제외/화면 꺼짐 테스트 필요.
